One room, one joint model

This portable PD Insighter demo shows the preserved RoomScan3c kitchen-room reconstruction, with a 90-second synchronized video excerpt. It reproduces viewing an existing result, not training it from raw data.

Method

Project Aria Tools reads the original RGB images, timestamps, camera calibration and MPS outputs. Selected frames were rectified to upright, 90-degree pinhole images and aligned with the calibrated camera poses in one metric MPS world frame. The semi-dense point cloud initialized the scene.

A single OpenSplat model was trained across 783 selected views from the approximately 24-minute room scan for 30,000 iterations on Apple MPS. People/phone foreground masks excluded unreliable moving-image regions from the background objective. The schedule starts at 704 pixels, then uses 1408 pixels; full training inputs are not in this mini package.

GaussianSplats3D and Three.js render the scene in the browser. PD Insighter synchronizes video frames, recorded camera positions/orientations and route navigation. The unchanged PLY is included; the web renderer uses SH2 appearance, while the offline trainer/evaluation uses SH3.

Included data and timing

The review MP4 covers original exported video 390-480 seconds (frames 11,700-14,399), keeps all 2,700 frames at 30 fps and is compressed to 704 x 704. The demo timeline resets to zero. Original RGB capture-relative times, pose values and support flags are retained without interpolation. The complete static room model and measured room landmarks are included, but the displayed route contains only this excerpt.

Limitations

No action labels were generated for this dedicated room scan. The moving camera is represented by a marker and frustum, not a reconstructed body. Blur, holes and foreground remnants remain, especially on reflective, occluded and poorly observed surfaces. Model availability is not a surface-coverage score, metric-accuracy guarantee or clinical validation.

Existing held-out comparison

Original validation panel from the room experiment, not a new test of this demo. Appearance agreement on held-out views does not establish independent geometry accuracy.

Reproduce or extend?

For viewing: run python3 start_demo.py. For checking download integrity: python3 start_demo.py --verify. For retraining: request the full VRS/MPS, selected images, masks, split and processing scripts from the larger research package.
